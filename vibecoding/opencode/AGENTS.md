# Focus
Always focus on implementing the requirements using the minimal needed code. Don't plan for undefined or unscoped situations. Of course use as much code as needed to make the solution functional. Do no omit code for the sake of minimizing code.

# Verification
Always validate changed files using the fastest relevant checks, such as syntax checks, formatting, compilation, type checking, or focused existing tests. If a check finds an error caused by your changes, fix it and rerun the check.

Do not add new tests, test infrastructure, or unrelated test coverage unless explicitly requested by the user.
